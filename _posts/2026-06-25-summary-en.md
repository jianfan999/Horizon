## [Nub: A Bun-like All-in-One Toolkit for Node.js](https://github.com/nubjs/nub) ⭐️ 8.0/10

Nub is a new open-source toolkit that brings Bun-like developer experience to Node.js by using a preload hook to add transpilation, module resolution, and polyfills while running code on stock Node.js. This project addresses a key pain point for Node.js developers by offering a zero-config setup that delivers faster TypeScript execution and modern API support without requiring a full runtime switch. Nub uses the oxc transpiler, packaged as a Node-API add-on, for high-speed TypeScript transformation, and injects polyfills for APIs like Worker and Temporal. It operates entirely via a --require preload hook and a module resolution hook, making it purely additive.

hackernews · colinmcd · Jun 24, 14:14 · [Discussion](https://news.ycombinator.com/item?id=48660267)

**Background**: Bun is a fast JavaScript runtime that includes a built-in transpiler, bundler, and package manager, offering a streamlined developer experience. Node.js traditionally requires separate tools like Babel or ts-node for TypeScript support. The oxc project is a Rust-based toolchain for JavaScript that provides high-performance linting and transformation.

## [Rust community discusses GitHub dependency for crates.io publishing](https://infosec.exchange/@mttaggart/116806641273303255) ⭐️ 8.0/10

The Rust community has renewed discussions about removing GitHub as a dependency for publishing packages to crates.io, with a recently merged RFC and initial implementation steps, but progress remains slow due to volunteer-driven development. This issue is critical because crates.io is the primary package registry for Rust, and its reliance on GitHub creates a single point of failure and centralization risk for the entire Rust ecosystem. The RFC #3963 was recently merged to unblock the decoupling effort, and a long-term roadmap exists with specific tasks. However, the work is often uninteresting and unfunded, relying on volunteers and occasional sponsorship.

hackernews · speckx · Jun 24, 19:40 · [Discussion](https://news.ycombinator.com/item?id=48664733)

**Background**: Crates.io is the official package registry for the Rust programming language, where developers publish libraries (crates). Currently, publishing a crate requires a GitHub account for authentication, as crates.io uses GitHub OAuth. This dependency has been a long-standing concern, as it ties the open-source ecosystem to a single commercial platform.
