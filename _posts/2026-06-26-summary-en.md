Weave released an open-source model router that integrates with coding agents like Claude Code, Codex, and Cursor, intelligently routing each inference request to the most suitable LLM based on a trained RL model. It is source-available under Elastic License 2.0.

hackernews · adchurch · Jun 26, 16:40 · [Discussion](https://news.ycombinator.com/item?id=48688700)

**Background**: Model routing is a technique that dynamically selects which LLM to use for a given request, optimizing for cost, speed, or accuracy. Coding agents like Claude Code and Cursor are AI tools that autonomously perform software development tasks, often incurring high API costs. The Weave Router acts as a transparent proxy between the agent and various LLM endpoints.
