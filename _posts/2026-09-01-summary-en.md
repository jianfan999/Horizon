## [Google Removes MV2 Extensions Like uBlock Origin from Chrome Web Store](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 8.0/10

Google has removed Manifest V2 (MV2) extensions from the Chrome Web Store, including the popular ad-blocker uBlock Origin. This follows through on Google's long-announced transition to the Manifest V3 extension format. This affects millions of Chrome users who depend on uBlock Origin and similar extensions for ad-blocking and privacy. It also intensifies debates about Google's control over the web and pushes users toward alternatives like Firefox. The change is part of the multi-year shift to Manifest V3, which replaces the webRequest API with the more restrictive declarativeNetRequest API, limiting how ad blockers can filter network traffic. A lighter version, uBlock Origin Lite, remains available on the Chrome Web Store but with reduced capabilities.

hackernews · twapi · Aug 31, 21:10 · [Discussion](https://news.ycombinator.com/item?id=49514878)

**Background**: Chrome extensions are declared in a 'manifest' file. In 2021, Chrome 88 introduced Manifest V3, which Google says improves security and performance. However, critics argue that V3's changes, particularly restrictions on blocking network requests, unfairly target ad blockers. uBlock Origin is a free, open-source content filter that relies on MV2's powerful blocking capabilities. Firefox continues to support MV2, and many users report that uBlock Origin works best there.

## [AI Could Curb Government Hacking Tools and Revive Backdoor Debate](https://techcrunch.com/2026/08/31/how-ai-could-make-it-harder-for-governments-to-use-hacking-tools/) ⭐️ 7.0/10

AI models, especially large language models, are becoming increasingly effective at finding and exploiting software vulnerabilities. According to NPR, Anthropic's latest model, Mythos Preview, was able to find high-severity vulnerabilities in every major operating system and web browser, which could make it harder for governments to use hacking tools and spyware and may reignite calls for device backdoors. This development matters because it shifts the balance between offensive and defensive cybersecurity. If AI can find vulnerabilities faster, governments' stockpiles of zero-day exploits become less valuable, potentially prompting renewed debates about backdoors and surveillance while affecting security policy, tech companies, and citizens' privacy. CSET's analysis notes that LLMs help at three key stages of the software vulnerability lifecycle: discovery, patching, and exploitation. The Internet Society warns that government hacking tools and exploits can be repurposed by adversaries, while the EFF criticizes these practices as lacking adequate judicial oversight and transparency.

rss · TechCrunch · Aug 31, 15:19

**Background**: Zero-day vulnerabilities are security flaws in software, hardware, or firmware that are unknown to the vendor and therefore have no patches. Government hacking tools often rely on such secret vulnerabilities for surveillance. AI is now increasingly used to discover and patch these flaws, which can both aid defenders and undermine the vulnerability stockpiles governments depend on. If governments can no longer rely on secret vulnerabilities, they may push for built-in device backdoors, but this would reduce security for all users.
